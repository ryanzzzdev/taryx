Taryx portal — UI design demos

Two high-density directions for the operator console. Same data, same workflow — different structure. Open each and compare; theme choice is shared via localStorage.

Design A — Operations console

Mission-control layout. Fixed left rail (accounts/cohorts/filters), dense centre workspace, right rail for exceptions and the live event feed. Everything one click away; nothing in dialogs.

  • Best for: heads-down operator throughput, watching state change live
  • Pipeline shown as three side-by-side stages with status chips
  • Quarantines, migration diffs and audit events always on screen
Open demo → 3-pane · status-dense · event feed

Design B — Enterprise suite

Classic ERP pattern: top tabs, filter bar, master table above a detail pane with fieldset sections. Familiar to anyone who has used SAP / Salesforce back-office tools.

  • Best for: record-centric review, audit-friendly document drill-down
  • Master-detail: account table selects the detail pane below
  • Rating lines + journal postings side by side in one document card
Open demo → tabs · master-detail · fieldsets
